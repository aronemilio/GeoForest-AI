# GeoForest-AI Huánuco

Sistema experimental de alerta temprana para identificar
posibles cambios en la cobertura forestal y quemas agrícolas
en el Bosque de Carpish y el Valle del Huallaga, Huánuco, Perú.

## Tecnologías previstas

- Python
- Sentinel-2
- Geobosques MINAM
- PyTorch y U-Net
- ONNX Runtime
- Streamlit
- Leaflet

## Estructura

- data/: datos satelitales y máscaras de entrenamiento.
- models/: modelos de IA.
- src/: procesamiento, arquitectura e inferencia.
- app/: interfaz de usuario.
- tests/: pruebas automatizadas.
- docs/: documentación técnica.
